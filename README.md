# Text-to-Speech Converter

🔊 A simple Java application that converts text into speech.

## 📌 Description

This application allows users to convert written text into spoken audio.  
It is designed to be simple and beginner-friendly, with basic controls for speech and text management.

## 🛠️ Tech Used
- Java
- Text-to-Speech (TTS) libraries

## ✨ Features
- Convert text into speech output
- Supports up to 5 lines of text at a time
- Simple and easy-to-use interface
- "Speak" button to play audio
- "Clear" button to remove all text instantly

## ⚙️ How It Works
1. Enter text into the input field
2. Click the **Speak** button to hear the audio
3. Click the **Clear** button to reset the text

## 🎯 Purpose

This project is part of my learning journey in Java development.  
It demonstrates how text-to-speech functionality can be implemented in a simple application.

This project is also intended as a basic learning resource for beginners.
